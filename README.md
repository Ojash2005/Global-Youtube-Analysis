# Global YouTube Statistics – Exploratory Data Analysis

An exploratory data analysis project using Python to investigate global YouTube channel statistics across 100+ countries. The project focuses on data cleaning, preprocessing, missing-value handling, feature engineering, statistical analysis, and data visualization to understand patterns in channel performance.

### Key Features
- Data cleaning and preprocessing using Pandas and NumPy.
- Handling missing values and inconsistent records.
- Feature engineering through country-to-continent mapping.
- Univariate, bivariate, and multivariate analysis.
- Analysis of subscribers, video views, uploads, and estimated earnings.
- Correlation analysis and heatmap visualization.
- Data visualization using Matplotlib and Seaborn.

### Tech Stack
Python | Pandas | NumPy | Matplotlib | Seaborn | Jupyter Notebook

### Objective
To explore global YouTube performance trends, identify relationships between channel metrics, and derive meaningful insights from data.
